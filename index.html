Ciao! Questa guida ti aiuterà passo per passo a configurare Minecraft su Windows. Non serve essere esperti: ogni passaggio è spiegato nel dettaglio.

01

Installa SKLauncher e crea un'istanza Fabric

Il launcher è il programma che avvia Minecraft. Consigliamo SKLauncher perché permette di installare Fabric direttamente:

  1. Scarica SKLauncher da skmedix.pl e installalo
  2. Apri SKLauncher e vai nella scheda Installations Manager
  3. Clicca + (New Installation) e dalle un nome
  4. Scegli Fabric come tipo e seleziona la versione del tuo mondo (1.20.1, 1.21.1 o 26.2)
  5. In More Options, imposta una Game Directory dedicata — ad esempio .minecraft-aria-classic, .minecraft-aria-cobblemon o .minecraft-aria-latest a seconda del mondo scelto. Non serve crearla prima: basta scrivere il percorso, SKLauncher la crea da sé al primo avvio
  6. Clicca Save, selezionala nella home e avviala una volta per scaricare i file. Chiudila subito appena compare il menu principale

Importante: senza una Game Directory dedicata, tutte le tue istanze Fabric condividono le stesse mod, mondi e opzioni. Se hai già altre installazioni modate, il passo successivo (che elimina la cartella mods) cancellerebbe anche quelle. Se vuoi giocare a più di uno dei tre mondi AriA, ogni mondo ha bisogno della propria Game Directory.

Se hai già acquistato Minecraft e preferisci il Launcher Ufficiale, dovrai installare Java da adoptium.net e Fabric manualmente tramite il Fabric Installer (versione 1.20.1).

02

Installa le Mod

Le mod richieste dal server: senza di esse non ti farà connettere.

  1. In SKLauncher, fai clic destro sulla tua istanza Fabric e seleziona Open Folder
  2. Se esiste già una cartella mods, eliminala completamente (clic destro → Elimina)
  3. Crea una nuova cartella vuota chiamata mods
  4. Scarica il file mod del tuo mondo (mods.zip, mods-cobblemon.zip o mods-latest.zip) dalla cartella condivisa (richiede account Google)
  5. Apri lo zip, seleziona tutto (Ctrl + A) e trascinalo nella cartella mods
03

Avvia il Server

  1. Apri l'AriA Panel e clicca Start
  2. Aspetta qualche minuto: il pannello mostra lo stato in tempo reale
  3. Quando compare l'IP il server è pronto

Il server si spegne in automatico quando non ci sono giocatori. Non preoccuparti di spegnerlo manualmente.

04

Collegati al Server

  1. In SKLauncher, seleziona la tua nuova istanza e clicca Play
  2. Nel menu principale: Multigiocatore → Connessione Diretta
  3. Incolla l'IP mostrato nell'AriA Panel (es. 1.2.3.4:25565)
  4. Clicca Connetti e buon divertimento!

There are three servers, each running a different Minecraft version with a different mod set. Pick the one you want to play and use its values throughout this guide.

Hey! This guide walks you through setting up Minecraft on Windows step by step. No experience required.

01

Install SKLauncher and create a Fabric instance

The launcher is the app that starts Minecraft. We recommend SKLauncher because it can install Fabric directly:

  1. Download SKLauncher from skmedix.pl and install it
  2. Open SKLauncher and go to the Installations Manager tab
  3. Click + (New Installation) and give it a name
  4. Select Fabric as the type and choose your world's version (1.20.1, 1.21.1 or 26.2)
  5. Under More Options, set a dedicated Game Directory — for example .minecraft-aria-classic, .minecraft-aria-cobblemon or .minecraft-aria-latest depending on the world you picked. No need to create it first: just type the path, SKLauncher creates it on first launch
  6. Click Save, select it on the home screen and launch it once to download the files. Close it as soon as the main menu appears

Important: without a dedicated Game Directory, every Fabric installation you have shares the same mods, worlds and options. If you already have other modded installs, the next step (which deletes the mods folder) would wipe those out too. If you want to play more than one of the three AriA worlds, each one needs its own Game Directory.

If you own Minecraft and prefer the Official Launcher, you'll need to install Java from adoptium.net and Fabric separately using the Fabric Installer (version 1.20.1).

02

Install the Mods

  1. In SKLauncher, right-click your Fabric instance and select Open Folder
  2. If a mods folder exists, delete it entirely (right-click → Delete)
  3. Create a new empty mods folder
  4. Download your world's mod file (mods.zip, mods-cobblemon.zip or mods-latest.zip) from the shared folder (Google account required)
  5. Open the zip, select all (Ctrl + A) and drag into mods
03

Start the Server

  1. Open the AriA Panel and click Start
  2. Wait a few minutes: the panel shows live status
  3. When the IP appears, the server is ready

The server shuts down automatically when no players are online.

04

Join the Server

  1. In SKLauncher, select your new instance and click Play
  2. In the main menu: Multiplayer → Direct Connection
  3. Paste the IP from the AriA Panel (e.g. 1.2.3.4:25565)
  4. Click Join Server and have fun!

Common Issues

ProblemSolution
Game crashes on launchDelete mods and re-extract from scratch
Fabric instance missingRedo step 1 and make sure you selected Fabric and your world's version (1.20.1, 1.21.1 or 26.2)
Seeing mods from another world, or ones I didn't installYou didn't set a separate Game Directory for this instance (see step 1) — your installations are sharing the same mods folder
